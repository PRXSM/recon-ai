How to find your IP address
🪟 Windows
  1. Press the Windows key + R at the same time
  2. Type cmd and press Enter
  3. In the black window, type ipconfig and press Enter
  4. Look for IPv4 Address — it starts with 192.168 or 10.
  5. Copy that number and paste it here
🍎 Mac
  1. Click the Apple menu (top left) → System Settings
  2. Click Wi-Fi (or Network)
  3. Click Details next to your connected network
  4. Your IP address is shown — it starts with 192.168 or 10.
  5. Copy that number and paste it here
🐧 Linux
  1. Open a terminal
  2. Type hostname -I and press Enter
  3. The first number shown is your IP address
  4. Copy that number and paste it here
💡 Tip: If Recon AI detected your IP automatically above, you probably don't need to change anything. Just hit Run Scan.
